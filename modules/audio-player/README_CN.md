# Audio Player

> 本插件由三个上游合并而成：**Media Marker**（Blontern，MIT，功能基底）、
> **Audio Timestamp Player**（ITNQ18，0BSD，多录音绑定 / 跨视图存活 /
> 源码模式点击）与 **Timestamp Player**（Len Zhou，MIT，其说话人时间戳与
> 区段作用域均已被基底涵盖）。出处与移植矩阵详见 [NOTICE](NOTICE)。

点击转录文稿中的时间戳即可跳转并播放嵌入的音频/视频，内置自定义播放器、媒体吸附、字幕与快捷键支持。

# 功能展示

## 可点击时间戳

笔记中，在视频下方写入的时间戳格式文本`[HH:]mm:ss[.SSS]`会渲染为按钮。点击即可让关联媒体跳转到对应位置并开始播放。播放过程中，当前时间戳会高亮显示，其图标随播放状态在播放/暂停之间切换。

## 循环播放时间戳

在笔记中写入 `[loop]起始时间戳->结束时间戳`，点击渲染出的区间即可循环播放该段。`loop` 标识符不区分大小写，表达式内的空格会被忽略，只要整个表达式位于同一行（例如 `[LoOp] 00:10     -> 00:20` 同样有效）。同一时间只能有一个循环；再次点击当前区间会停止循环。循环区间不会被当作普通时间戳统计。

## 自定义播放器

嵌入的 `audio` 与 `video` 会被替换为自定义控制栏：播放/暂停、带悬停提示的可拖动进度条、音量滑块、播放速度菜单（`0.5x` – `2x`）、字幕开关、画中画与全屏（视频），以及设置菜单。

## 视频跳转步进

共有三种粒度：帧/关键帧/5秒。

## 时间戳插入

一键将当前播放位置作为时间戳插入。新时间戳会按正确的时间先后顺序，插入到媒体源行下方的“时间戳队列”中。

## 媒体吸附

在滚动长篇转录文稿时，播放器会吸附到窗格顶部并跟随页面下移。当遇到下一个媒体块或当前时间戳区块结束时自动松开。可通过视图标题栏的吸附按钮按视图开关该功能。

## 字幕与歌词

将同名的 `.vtt`、`.srt` 或 `.lrc` 文件放在媒体旁即可启用字幕。视频显示单行字幕；音频则切换为滚动歌词视图，并支持同名封面图。

## 自定义快捷键

播放/暂停、快进快退、步长切换、音量、字幕开关、插入时间戳、全屏等操作均可绑定按键，并可在快捷键设置面板中重新绑定。

## 播放设置

设置后，可实时应用到每个播放器：

- 播放方式：播完暂停/循环播放
- 视频比例：自动/`4:3`/`16:9`
- 屏幕方向：横屏/竖屏
